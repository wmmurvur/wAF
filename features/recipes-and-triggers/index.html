Workflows

A chain where each step hands its output to the next. A step can be an agent, an HTTP call, an image or video job, a browser run, or a stop that waits for your yes.

The Plan tab and a recipe, live

What it solves

Work that needs several agents or tools in a row means copying one result into the next by hand, and waiting at the desk to do it.

How it works · pick a step

Workflows run in VS Code. If it closes in the middle of a parallel group, Resume runs the whole group again, and an approval waits until a window is open.

IV·2

Schedules

Daily, weekly or once at a date and hour. A missed run is skipped, caught up, or put to you. With VS Code closed, a small service on Windows still runs them.

Schedules on the Plan tab

What it solves

A morning plan or a weekly report should start without anyone pressing a button, and a night the laptop was shut should not leave you guessing what ran.

How it works · pick a step

The service runs Claude only, and only schedules and watch triggers; hooks, webhooks and workflows wait for VS Code. Only one window runs the scheduler, so two open windows never fire a schedule twice.

A watch trigger and its recipe, live

IV·4

Gatekeeper

Before a trigger wakes an agent, free local checks and then Jev, a model that never chats and only decides, say whether there is real work. Off, watching in the shadow, or on.

Gatekeeper saying no, live

What it solves

One folder watch woke opus 23 times over five nights, found nothing every time, and cost $70.90. A cooldown limits how often an agent wakes; it never asks whether there is anything to do.

How it works · pick a step

Rules come in layers, the built-in ones, yours, then a project's, the later one winning. Gatekeeper also comes as an MCP server with three tools, registered only when you ask.

Say it in words

Type "run the filing batch on manager now". A cheap model turns it into a task, a schedule or a workflow, and nothing is set up until you press Create.

The words box on the Runs tab

What it solves

Questions

Do schedules run with VS Code closed?

On Windows, yes, if you install the small headless service: it runs schedules and watch triggers with Claude while VS Code is closed. Or export a schedule as a Windows Scheduled Task.

How do I stop an empty folder from waking an expensive model?

Give the trigger a free check, such as "the folder has files", or put Gatekeeper on it. Without either, one watch once cost $70.90 in five nights of finding nothing.

What happens to a schedule in quiet hours?

It waits for the end of the window and then runs, marked deferred. A run you start yourself ignores quiet hours; the main switch still stops it.

How many runs go at once?

Two across the fleet and one per agent, by default. The rest wait, marked deferred, and start as slots free.

What if a run hits my usage limit at night?

It tries again by itself, after 40 minutes unless you set it otherwise. It can also wait for the plan's reset, or carry on on another signed-in account of the same engine.

Is Gatekeeper on by default? Is there a quick start?

Gatekeeper is off for every use; shadow shows how often it agrees with you before you turn it on, and it needs a key for Jev. For a quick start, one click sets up three examples: an inbox duty, a briefing at 09:00 and a two-agent chain.
