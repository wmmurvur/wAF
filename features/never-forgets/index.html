Every session kept. What mattered becomes a wiki.

Every conversation on this machine is kept, from every engine, with what it cost. Mark the turn that mattered; nothing is written yet. Later one run reads the marked turns and writes wiki pages into your Obsidian vault, one concept to a page, each with its sources.

Vault · Obsidian

You curate, agents write. Pages are plain Markdown in your own vault; the links between them are what Obsidian draws as a graph.

Questions

Does Agent Farm copy my conversations somewhere?

No. They stay where each CLI writes them. Agent Farm reads them, and keeps an index and a search cache it can rebuild at any time; even renaming a session leaves its transcript untouched.

Do I need Obsidian?

The wiki is a folder of Markdown pages, written for Obsidian, where the links and the graph come alive. Pages can just as well open in VS Code or an app of your choice.

Does building the wiki cost money?

Marking costs nothing. A compile is one run on your wiki agent, metered like any task, and before it starts a strip shows the engine, model and effort it will use.

Does searching by meaning send my conversations out?

It is off until you choose a provider. With a cloud provider the passages go to it to be indexed; with Ollama everything stays on your machine. Text and regex search never leave it.

Can it read every old conversation?

Claude Code, Codex, Gemini and OpenCode, yes. Antigravity stored its older conversations in a form with no published schema, so only the ones Agent Farm hosted itself, which it writes out as plain JSON, open in full.

What is the difference between an agent's memory and the wiki?

An agent's memory is its own notes, loaded through its index into every session it starts. The wiki is shared knowledge, compiled from sessions for you and every agent, and it lives in your vault.
