V·1

Missions

A lead that cannot write plans round by round and hands the work to a team on different engines, one writer per folder, until the goal is met or one of five caps is reached.

A mission, live

What it solves

Some work does not fit in one agent: it needs planning, doing, reviewing and testing, and the next step depends on what the last one found. Drawing that as a fixed chain in advance means guessing.

How it works · pick a step

An adaptive mission takes an objective with criteria instead: independent tasks run side by side in waves, a reviewer is handed the real output of the task it reviews, and agents can hold a conversation in which each turn reads what the others actually wrote.

V·2

Shared sessions

Any agent can open any session by its id, whichever engine wrote it, see what was and wasn't done, and carry on.

What it solves

A session written by Claude Code is a file Codex cannot read, and the other way round. Work started by one engine stopped there, unless you copied the important parts across by hand.

How it works · pick a step

So the reviewer on Codex reads what the developer on Claude actually did, turn by turn, and carries on from there.

V·3

Agent notes

Agents leave each other notes and hand tasks over, with a guard against loops.

What it solves

Agents find things the next agent needs, a locked database, an API that changed, a result, and they find work they cannot do themselves. Telling you every time turns you into the postman.

How it works · pick a step

Agents look at the board when a session starts: a2a.status gives unread notes, tasks they could take and leases they hold in one call. A relay's handover shows there too, as a card that resolves itself when the next leg starts.

V·5

Console

Every session in one column: who is working, whose turn it is, which leg of which chain.

The Console, live

What it solves

Every CLI has its own terminal and its own habits. With eight sessions running at once you cannot tell which is working, which is stuck and which is waiting for you.

How it works · pick a step

Your install, your subscription: the Console runs the CLI you already have, and the transcript lands where it always does, so every other page keeps reading it. Files and screenshots drop or paste straight into the box, and saved prompt snippets are a right-click away.

V·6

Countdown questions

An agent's question picks the suggested answer when time runs out. A permission request always waits for you, with every stuck session, in Needs You.

Waiting for you, in the Console

What it solves

An agent asks a question at midnight, nobody is at the desk, and the whole night goes by waiting for one click.

How it works · pick a step

The agent is told the timer answered, not you, and the transcript marks each answer as yours or the recommended one. The clock runs in VS Code itself, so it keeps going with the Console closed.

V·7

Notices and the queue

Agents report, remind and ask on one board, by level, and your answer becomes work in the queue. Your side of it: leave a job for an agent, now or when its group fills.

What it solves

Agents have things to tell you that are not urgent, and you have small jobs for them that come to mind while you work on something else. Both get lost in chats.

How it works · pick a step

Needs You only holds what stays stuck if you never touch it. News, a blown budget or a proposal, goes to Notices, which is made to be read later. An agent that asks there can sleep until you answer, spending no tokens while it waits.

Questions

Can two agents edit the same files at once?

Not by accident. In a mission with a working folder, writers take turns and only read-only steps share a wave. For jobs that should run side by side, each gets its own git worktree and branch.

Can a mission run away with my plan?

No. Every mission has five caps, cost, rounds, tasks, minutes and tasks at once, and when one is spent the lead may only finish. Repeating the same work to the same agent is refused.

What if nobody answers an agent's question?

When the countdown ends, the answer the agent recommended goes in, and the agent is told it was the timer. A destructive question and a tool permission are never answered on a clock: they wait in Needs You.

Can agents on different engines work on the same thing?

Yes. A mission's team can mix Claude Code, Codex, Gemini CLI, Antigravity and OpenCode, and any agent can read any engine's session in the same words.

Do agents talk to each other?

Through notes and tasks on the A2A board, and in an adaptive mission through a conversation in which each turn is shown what the others actually wrote. Nothing reaches you unless it is for you.

What is the difference between Notices, the queue and Needs You?

Notices is what agents tell you. The Work Queue is what you give them. Needs You is only what stays stuck until you act: a permission, a question no timer answers, a stalled session.
