Never stops

Work keeps going through full contexts, full accounts and its own updates.

A long job outlives any one session. When a context fills, a fresh session takes over from a handover note. When an account's window fills, the next leg opens on another account. When every account is full, the chain waits for the reset and carries on. You set the lines and the brakes once.

I·1

Baton relay

At the context level you set (40% by default), a session commits, writes a handover note and a fresh session carries on. No context rot.

Watch a chain run for three days

What it solves

A long session gets worse as its context fills: it loses the start, repeats itself and begins to guess. Starting over by hand means explaining everything again.

How it works · pick a step

The two lines reach a running session through Claude Code's hooks. On the other engines the crossing is recorded on the session card as undelivered, so it is never assumed to have been said.

I·3

Account policies

Four built-in rules (@emptiest, @pool, @standing, @round-robin) or your own. A rule that can pick no account refuses the launch and says why.

What it solves

Which account a session runs on is a decision. Making it by hand at every launch is how the wrong plan gets drained.

How it works · pick a step

The setting's own example: {"name": "Night", "chain": [{"account": "spare"}, {"policy": "@emptiest", "ceiling": 80}]} is @Night. It tries the spare account first, then the emptiest one under 80%.

Ouroboros

An agent builds a new Agent Farm, restarts it inside VS Code and carries on in the same session. Nobody has to restart anything.

Watch it on the home page

What it solves

An agent that improves Agent Farm itself needs the new build running. Restarting VS Code's extensions would normally cut off every session, its own included.

How it works · pick a step

There is no button and no setting for this. It is something an agent does over the bridge (farm.restartExtensionHost, with resume), behind fixed guards.

Questions

Does the next session remember anything?

It starts fresh, on purpose: a session already at the handover line would walk straight back into the wall. What carries over is what the last leg wrote, its handover note and the words it passed, plus your standing rule.

I have one account. Is this for me?

Yes. The relay still hands over at the context line. When that account's window fills, the chain parks until its reset and carries on by itself.

Does it work on engines other than Claude Code?

The next leg opens on the same engine as the leg before it. The converge and handover lines reach a running session through Claude Code's hooks; on the others the crossing is recorded on the session card as undelivered, so you can see it was not said.

Can a chain run for ever?

Only if you let it: set the leg ceiling to 0. The barren-chain brake still stops a chain whose legs stop committing, and you can stop it at any time.

What happens at night when every account is full?

The next leg parks until the first reset, plus 3 minutes, and starts by itself. Notices tells you when; in the morning the chain has carried on.
