13 Just ask

The bridge · one shell command · 579 operations

You never have to learn any of this. Just ask.

Every session is told at its start how to reach the farm. So you say it in one sentence and the agent does it: it reads what the farm can do, then calls it, one command at a time. Each call shows up as a notification. Nothing is done behind your back.

VIII·2

579 operations

What you can do with a click, an agent can do with a call: a button with no operation fails the build. A few things stay yours on purpose: granting a tool permission, stopping a question's countdown, and a secret's value. New abilities show up in farm.ops by themselves.

"What can you do in the farm?", live

What it solves

If an agent can do only half of what you can, every request ends with "open the page yourself".

How it works · pick a step

The full catalog, farm.ops full=true, is large, so it is written to a file with --out and never read into a model's context. An agent can ask about itself too: sessions.whoami names the session it is, worked out from its own process tree, never guessed from the folder, where several sessions often run at once.

VIII·3

One command line

The bridge is a single shell command, so any agent that can run a command can use the farm. Gatekeeper also comes as an MCP server.

The calls as they happen, live

What it solves

A tool only one kind of agent can call splits the fleet in two: the agents that can drive the farm and the ones that cannot.

How it works · pick a step

A call waits 20 seconds by default. If it times out, af.js says which: the farm took it and is still running, or nobody took it and nothing ran. With VS Code closed, the request waits for the next window.

VIII·4

Agents with a home

Each agent keeps its own identity, duties that run every turn or session, and tools. The Toolbox shows every skill, subagent, command, MCP server, hook and plugin on the machine, adds new ones and tests what an MCP server really offers.

What it solves

An agent that is only a prompt forgets what it is for, and the standing agreements you made with it end up scattered in old chats.

How it works · pick a step

Duty templates set up the common ones in one pick: a question-and-answer loop, inbox triage, weekly memory upkeep, an output folder. A duty can be copied to another agent.

VIII·7

Telegram

A Telegram chat talks to your agents. A card arrives when a turn ends or asks, and one tap answers it. Only the chats you allow, within a daily budget.

Telegram on the phone, live

What it solves

A turn that ends while you are out should reach you where you already are, and your reply should reach the agent.

How it works · pick a step

The budget counts every turn of a session started from the chat, wherever the turn was typed. Notifications can also go to a webhook of your own: permissions, stalls, budgets, a workflow done or failed, the weekly summary, and once a day a scorecard of the cost, the agents, the top spenders and the warnings, made without calling a model.

VIII·9

Read aloud

An answer, a selection or the daily briefing read aloud, each in its own language, and whoever is asking named after the tone.

Read aloud, live

What it solves

A tone says that something happened. It cannot say which agent, or what it said, and for most turns the answer is one sentence long.

How it works · pick a step

Reading is not an alert. A muted farm still reads the session you asked it to, and a long reading never holds the short tones up behind it.

Questions

Can an agent approve its own permissions?

No. An agent can answer a question through the bridge, but granting a tool permission stays with you: in the panel, on your phone or in Telegram. Only you can stop a question's countdown, too.

Do I have to learn the bridge?

No. Every session is told at its start how to reach the farm, and an agent looks up the rest in the farm's own manual. You say what you want; each call it makes shows as a notification.

Does the bridge work with VS Code closed?

The manual answers at once. Anything that changes the farm waits for the next VS Code window; af.js gives up after 20 seconds and tells you whether anything ran.

Can strangers write to my agents on Telegram?

Only the chats on your list are heard; with an empty list, every message is refused. Turns started there have a daily budget, $1 out of the box, and a risky-looking command asks before it runs.

What does a phone wake-up send through Google?

Only that there is something new, and which farm. The phone then reads the rest straight from your machine over its own encrypted connection.

What does an agent pack leave out?

Its memory and its secrets, files that look like credentials, and webhook tokens. The triggers and schedules in it arrive switched off.
